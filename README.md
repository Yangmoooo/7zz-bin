# 7zz-binaries

This repository automatically builds and packages `7zz` (standalone console) and `7z.dll` (format plugin DLL) for Windows, plus `7zz` and `7zzs` for Linux. The build is triggered whenever a new version of [7-Zip](https://github.com/ip7z/7zip) is released.
